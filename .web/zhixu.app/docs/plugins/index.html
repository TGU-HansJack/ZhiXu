插件文档（Android）

插件以文件夹安装，Actions 驱动能力扩展。

安装方式（使用者）

在应用内进入：设置 → 创意工坊。

  • 本地安装：选择一个包含 manifest.json 的文件夹。
  • Git 安装：填写一个可访问的 Git 仓库地址（仓库根目录必须包含 manifest.json）。

安装后可启用/停用插件；点 Settings 可编辑该插件的 config.json。

目录结构（开发者）

my-plugin/
  manifest.json
  main.js
  README.md            # 可选，用于“查看详情”
  config.json          # 可选，默认可由应用创建/编辑

manifest.json 规范

必须字段：

  • id：插件 ID（同时作为安装目录名），建议使用小写、短横线，如 typecho-xmlrpc-publisher。

推荐字段：

  • name：插件名称
  • version：版本号
  • description：简介
  • entry：JS 入口文件名（默认 main.js；如果写成 foo 会尝试 foo 和 foo.js）
  • actions：动作列表（用于编辑器浮动按钮）

actions[] 字段：

  • id：动作 ID（JS 中对应函数名）
  • label：按钮文案
  • icon：图标名（当前内置简易映射）
  • place：动作位置（目前支持 editor_fab；为空也视作 editor_fab）
  • ringIndex：在圆形菜单中的分组/层级（整数）
{
  "id": "hello-plugin",
  "name": "Hello Plugin",
  "version": "0.1.0",
  "description": "A demo plugin",
  "entry": "main.js",
  "actions": [
    { "id": "hello", "label": "Say Hello", "icon": "publish", "place": "editor_fab", "ringIndex": 0 }
  ]
}

JS 入口与 actions

入口文件以 CommonJS 形式导出：

function hello(context) {
  api.log("hello called");
  return { ok: true, message: "Hello from plugin!" };
}

module.exports = {
  actions: { hello },
};

触发时调用：module.exports.actions[actionId](context)。

context（上下文）

  • context.note：docUri、title、fileName、text
  • context.config：插件 config.json（对象；不存在则为空对象）
  • context.plugin：id / name / version
  • context.app：platform（android）、versionName

api（内置能力）

  • api.log(any)：写入日志（Logcat tag：ZhixuPlugin）。
  • api.http(method, url, body?, contentType?)：同步 HTTP 请求，返回响应体字符串；非 2xx 抛异常。
function ping(ctx) {
  const text = api.http("GET", "https://example.com/");
  return { ok: true, message: "len=" + text.length };
}

返回值（动作执行结果）

  • string：作为提示信息展示。
  • object：可包含 ok（布尔）、message（字符串）、setText（替换当前文档并保存）。
function appendTimestamp(ctx) {
  const next = ctx.note.text + "\\n\\nupdatedAt: " + new Date().toISOString() + "\\n";
  return { ok: true, message: "Updated", setText: next };
}
