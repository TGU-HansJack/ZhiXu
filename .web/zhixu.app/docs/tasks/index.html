Markdown 任务语法

任务身份由 @id(...) 保证跨端一致。

核心原则

  • 任务身份 = 行内 @id(...)（跨端一致，可写回 Markdown）。
  • 索引是派生物：解析结果写入索引库用于检索/提醒，索引库可重建。
  • MVP：首次索引时为缺失的任务补 @id(...) 并写回文档。

MVP 语法

- [ ] 标题 @due(2026-01-10 09:00) @tag(work) @id(01J...)
- [x] 标题 @done(2026-01-10 10:03) @id(01J...)

字段约定（建议）

  • @id(<ulid>)：任务唯一标识（建议 ULID）。
  • @due(YYYY-MM-DD HH:mm)：到期时间（本地时区）。
  • @done(YYYY-MM-DD HH:mm)：完成时间。
  • @tag(xxx)：标签（可重复）。
  • @priority(high) 或 p(1..4)：优先级（建议统一一种写法）。
  • @rrule(...)：重复规则（iCalendar RRULE，后续版本逐步支持）。

解析与容错

  • 允许任务行出现在任意 Markdown 文档中。
  • 忽略未知 @xxx(...) 字段（向前兼容）。
  • 字段格式错误时保留原文，不阻断整行解析。
