常见问题

如果这里没有你需要的答案，请发邮件联系我们。

数据存在哪里？

默认存储在你选择的本地 Vault（一个普通文件夹）中，以文件形式存在。

删除应用会丢数据吗？

不会。只要 Vault 文件夹还在，你可以重新安装后继续使用。索引库属于可重建数据。

同步会上传哪些内容？

以文件为单位同步整个 Vault，可根据策略忽略可重建文件。详见 同步协议。

插件安全吗？

插件是可执行的 JS 代码，可能访问网络并修改当前文档内容。只安装你信任来源的插件，并优先使用只读/可审计的工作流。
