文档

面向使用者与插件开发者的“核心语义”文档。

快速开始

  • 下载并安装 Android 版：zhixu.app
  • 首次启动选择或创建一个 Vault（一个普通文件夹）。
  • 在 Vault 的 docs/ 里创建 Markdown 文档并编辑。
  • 在 Markdown 中使用任务语法（如 - [ ] 与 @id(...)）建立可同步的待办。
  • 需要跨设备时再开启同步（例如 WebDAV），保持“文件级边界”。

Vault（数据边界）

Zhixu 的核心原则是：数据以文件为边界，可迁移、可导出、可备份。应用的索引/缓存不等于数据本身，可删除重建。

推荐目录结构：

VaultRoot/
├─ docs/                 # 全部 Markdown 文档
├─ attachments/          # 图片 / 音频 / 文件
└─ .zhixu/
   ├─ index.sqlite       # 索引库（可删除重建）
   ├─ settings.json      # Vault 设置
   └─ sync/              # 同步元数据/冲突日志

阅读：Vault 规范

任务语法（跨端稳定）

任务身份使用行内 @id(...) 保持稳定（而不是依赖数据库自增 ID）。

- [ ] 标题 @due(2026-01-10 09:00) @tag(work) @id(01J...)
- [x] 标题 @done(2026-01-10 10:03) @id(01J...)

阅读：任务语法

同步（文件级协议）

同步以文件为单位比较与传输，并把冲突记录为可追溯的文件与日志。

阅读：同步协议

插件（Actions 驱动的扩展）

插件以文件夹形式安装到 .zhixu/plugins/<pluginId>/，由 manifest.json 描述，并通过 JS 入口导出 actions 供编辑器触发。

阅读：插件文档（安装 + 开发）
