## 0.3.3

### 新功能
- 新增：Android 文档列表支持置顶与多选操作，选中模式交互更完善
- 新增：Android 首页顶部栏显示用户头像入口
- 新增：Android 相机功能入口，并重构抽屉导航栏
- 新增：Android 设置页新增官方同步入口
- 新增：账号系统支持邮箱验证码验证（SMTP 可配置）与 JWT 刷新令牌会话
- 新增：插件系统支持待办插件与通知提醒，并开放插件 API / WebDAV 同步插件列表
- 新增：绘图笔触支持压力与倾斜检测

### 优化
- 优化：Android 文档列表界面与本地化文案，时间展示更清晰
- 优化：Android 悬浮按钮样式与暗色主题适配
- 优化：编辑器头部导航/面包屑/文件名编辑等交互体验，并改善滚轮/高 DPI 显示细节
- 优化：桌面端系统托盘与滚动条样式细节

### 修复
- 修复：Android 文档列表默认显示模式问题
- 修复：文档列表分隔条颜色等 UI 细节
- 修复：桌面端标签页样式与关闭按钮悬停提示问题
- 修复：代码编辑器语法高亮与行号显示异常
