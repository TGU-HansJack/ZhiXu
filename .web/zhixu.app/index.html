插件

插件以 .zhixu/plugins/<pluginId>/ 的形式安装在 Vault 中，由 manifest.json 描述，并通过 JS 入口导出可执行的 actions。

典型场景：模板插入、批量处理、与外部服务对接、会议纪要与行动项提取。

打开插件开发指南

设计原则

  • 文件夹即安装包：无需复杂安装器
  • Actions 即能力：UI 与能力解耦
  • Vault 即边界：数据可搬迁、可回滚

同步

Zhixu 从一开始就把“多端同步难”当成核心问题：用一致的数据模型与协议，降低同步与冲突处理的复杂度。

目标是让 Android / Web / Desktop 都能复用同一套核心语义，而不是各端各写一套“差不多”的规则。
