功能亮点

Vault（本地文件夹）

数据就是一个普通目录：可备份、可迁移、可导出；索引/缓存可删可重建。

Markdown 编辑与预览

CodeMirror（WebView）+ 源码/实时预览；表格/任务列表/代码高亮，内置 KaTeX、Mermaid、PDF/图片与长图导出。

任务语法（@id）

用 - [ ] 与 @id(...) 保持任务身份稳定；支持截止/完成字段与本地统计。

OCR（本地）

集成 PaddleOCR v5：从图片生成可编辑文本/待办，默认离线完成识别。

AI（可选）

OCR+AI 整理与行动项提取；支持 OpenAI 兼容接口，启用后才会联网。

插件工作坊

JS Actions 扩展工作流：本地文件夹/官方列表/Git 仓库安装（插件为可执行代码）。

同步（官方 / WebDAV）

按文件对比与传输 Vault，冲突记录可追溯；规则与协议写进文档。

番茄钟

后台服务与通知 + 专注统计，让计划真正落到每天。

原生优先

插件

插件以 .zhixu/plugins/<pluginId>/ 的形式安装在 Vault 中，由 manifest.json 描述，并通过 JS 入口导出可执行的 actions。

典型场景：模板插入、批量处理、发布到博客、对接外部服务、会议纪要与行动项提取。

提示：插件是可执行代码，可能读取文档内容并发起网络请求，请仅安装信任来源。

打开插件目录 插件开发指南

设计原则

  • 文件夹即安装包：无需复杂安装器
  • Actions 即能力：UI 与能力解耦
  • Vault 即边界：数据可搬迁、可回滚

同步

同步是可选项：你可以使用官方服务（控制台管理账号/设备/同步记录），也可以使用 WebDAV 自建。核心原则仍然是以文件为边界，同步与冲突可追溯。

目标是让 Android / Web / Desktop 都能复用同一套核心语义，而不是各端各写一套“差不多”的规则。
