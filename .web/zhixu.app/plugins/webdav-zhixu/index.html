WebDAV 同步

将当前 Vault 与 WebDAV 远端目录进行同步（示例插件）。

功能

  • 测试连接（PROPFIND Depth 0）
  • 立即同步（示例实现：上传本地缺失/变更文件、下载远端缺失文件）

配置

编辑 config.json：

  • baseUrl：WebDAV 服务地址
  • remoteRoot：远端根目录
  • username / password：认证信息
