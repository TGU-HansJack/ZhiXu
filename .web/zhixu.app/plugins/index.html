安装提示

  • 在应用内进入：设置 → 创意工坊。
  • 选择“本地安装”或填写可访问的 Git 仓库地址进行安装。
  • 插件会被安装到当前 Vault 的 .zhixu/plugins/<pluginId>/。

开发文档：插件开发指南

可用插件

  • 待办 （任务 / 日历 / 四象限三合一待办插件）
  • WebDAV 同步 （将当前 Vault 与 WebDAV 远端目录进行同步）
  • Typecho XML-RPC 发布器 （将当前笔记通过 MetaWeblog API 发布到 Typecho）
