Typecho XML-RPC 发布器

通过 XML-RPC（MetaWeblog API）将当前笔记发布到 Typecho 博客。

用途

把当前笔记作为文章发布/更新到 Typecho，并支持同步文章时间、查看最近文章、删除文章等操作。

配置（创意工坊 → Settings）

编辑 config.json：

  • endpoint：Typecho XML-RPC 地址（通常类似 https://your.site/action/xmlrpc）
  • username / password：账号密码
  • blogId：默认 0
  • useFrontmatter：是否优先使用 frontmatter（如 title）作为发布字段
  • useCurrentTime：发布时是否强制使用当前时间
  • publishTimeOffsetHours：发布时对时间做偏移（小时）
  • syncTimeOffsetHours：从服务器同步时间时的偏移（小时）
  • managePostsCount：最近文章列表拉取数量
  • defaultCategories：frontmatter 未填写分类时的默认分类（数组）
  • frontmatterKeys：映射到你笔记 frontmatter 的字段名（title/cid/slug/tags/categories/draft/dateCreated/lastPublished）

操作

  • 发布：发布/更新（存在 cid 则调用 metaWeblog.editPost，否则 metaWeblog.newPost）
  • 同步时间：从服务器读取 dateCreated 并回写到笔记 frontmatter
  • 最近文章：获取最近文章列表（metaWeblog.getRecentPosts）
  • 删除：删除当前笔记对应文章（blogger.deletePost）
