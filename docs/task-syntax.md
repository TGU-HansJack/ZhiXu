# Markdown 任务语法（Zhixu 语义核心）

## 核心原则

- 任务身份 = `@id(...)`（跨端一致、可写回 Markdown）
- 索引是派生物：解析结果写入 SQLite 仅用于检索/提醒
- MVP：首次索引时为缺失任务补 `@id(...)` 并写回文件

## MVP 语法（最小闭环）

```md
- [ ] 标题 @due(2025-12-20 09:00) @tag(work) @id(01J...)
- [x] 标题 @done(2025-12-20 10:03) @id(01J...)
```

## 字段约定（建议）

- `@id(<ulid>)`：任务唯一标识（推荐 ULID）
- `@due(YYYY-MM-DD HH:mm)`：到期时间（本地时区）
- `@done(YYYY-MM-DD HH:mm)`：完成时间
- `@tag(xxx)`：标签（可重复）
- `@priority(high)` 或 `p(1..4)`：优先级（建议统一一种写法）
- `@rrule(<iCalendar RRULE>)`：重复规则（后置到 v0.2/v0.3）
- `from(<source>:<id>)`：来源引用（例如会议文档、转写任务）

## 解析与容错（MVP）

- 允许任务行在任意 Markdown 文档中出现
- 忽略未知 `@xxx(...)`（向前兼容）
- 对格式错误字段：保留原文，不阻断整行解析
